# Student-Project-Portal-

Full-stack project management portal for students &amp; professors
 
 Student Project Portal 🚀

 🎯 Features
- ✅ Student project submission with file upload
- ✅ Professor review system with grading (1-10)
- ✅ Peer rating system with average score
- ✅ Real-time notifications
- ✅ Advanced project search (domain, rating, status)
- ✅ Responsive dual dashboards (Student/Professor)

 🛠 Tech Stack
Frontend | HTML5, Bootstrap 5.1, CSS3 
Backend  | PHP 8.1 + PDO 
Database | MySQL 11.4 (InnoDB)  


🚀 Quick Start (Local)

1. Clone repo: `git clone <repo-url>`
2. Import `DATABASE.sql` into phpMyAdmin
3. Update `config.php` with your DB credentials
4. Start XAMPP → Visit `localhost`
